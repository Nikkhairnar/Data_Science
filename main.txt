| Plot Type    | Matplotlib Syntax (`plt`)        | Seaborn Syntax (`sns`)              |
| ------------ | -------------------------------- | ----------------------------------- |
| Line Plot    | `plt.plot(x, y)`                 | `sns.lineplot(x=x, y=y)`            |
| Histogram    | `plt.hist(data)`                 | `sns.histplot(data)`                |
| Scatter Plot | `plt.scatter(x, y)`              | `sns.scatterplot(x=x, y=y)`         |
| Bar Plot     | `plt.bar(x, y)`                  | `sns.barplot(x=x, y=y)`             |
| Box Plot     | `plt.boxplot(data)`              | `sns.boxplot(x=x, y=y, data=df)`    |
| Pie Chart    | `plt.pie(values, labels=labels)` | Not directly available              |
| Count Plot   | Not directly available           | `sns.countplot(x='col', data=df)`   |
| Heatmap      | Complex/manual                   | `sns.heatmap(data)`                 |
| Pair Plot    | Not directly available           | `sns.pairplot(df)`                  |
| Violin Plot  | `plt.violinplot(data)`           | `sns.violinplot(x=x, y=y, data=df)` |
| KDE Plot     | Complex/manual                   | `sns.kdeplot(data)`                 |

Accuracy=
Total Predictions
Correct Predictions

Confusion Matrix
Displays prediction results in matrix form.

It shows:

correct predictions
incorrect predictions
---------------------- 
*Format:

[
TN
FN
	​

FP
TP
	​

]

Where:

TN → True Negative
FP → False Positive
FN → False Negative
TP → True Positive
Separates confusion matrix values into individual variables.

TN → correctly predicted No
FP → wrongly predicted Yes
FN → wrongly predicted No
TP → correctly predicted Yes

accuracy = (TP + TN) / (TP + TN + FP + FN)
accuracy
error_rate = 1 - accuracy
error_rate
precision = TP / (TP + FP)
precision
recall = TP / (TP + FN)
